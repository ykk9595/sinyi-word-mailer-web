# 信義房屋物件明細表網站

GitHub Pages 靜態網站：貼上信義房屋物件網址後，透過唯讀轉接服務取得公開頁面資料，在瀏覽器內產生固定格式 Word，立即下載並透過 FormSubmit 寄送附件。

## 功能

- 讀取信義房屋公開物件頁資料，不需要信義房屋帳號或密碼。
- 使用內建空白母版，只修改 `word/document.xml` 文字內容。
- 將信義房屋的建物朝向、謄本用途與類型轉成母版對應欄位及代碼。
- 將信義房屋「物件特色」逐行填入 Word「物件特性」，最多五行。
- Word 會先下載到本機，即使寄信服務失敗也不會遺失文件。
- 收件信箱固定在程式設定中，網站畫面不顯示信箱輸入欄位。
- 使用 FormSubmit 官方支援的原生 `multipart/form-data` 表單寄送 Word 附件。
- Word 表頭與寄信主旨使用每個信義房屋物件自己的完整案件名稱。
- 下載檔名使用完整案件名稱，並自動替換 Windows 不允許的檔名字元。
- 固定填入開發人員比例、開發銷售比例與外商圈說明書簽名。
- 承辦人固定填入「楊明仁 0953-221-818」，不使用信義房屋頁面的經紀人資料。
- 依信義房屋資料填入管理費、繳費方式、車位、格局、樓層與使用狀況。
- 售價優先讀取物件詳情中的「總價」，避免降價物件誤用刪除線原價。
- 從周邊生活機能的學校分類讀取最近的國小、國中與高中，填入 Word 學區欄位。
- 從周邊生活機能「休閒 → 公園」讀取最近的公園，填入 Word「公園綠地」。
- 從周邊生活機能「購物 → 超市」讀取店名，依距離順序填入 Word「市場購物」。
- 建物格局會將正式格局與加蓋格局相加，與信義房屋頁面上方顯示的總格局一致。
- 不在網站中保存 Gmail 密碼或其他郵件憑證。

## 第一次啟用寄信

FormSubmit 第一次收到網站提交時，會寄一封啟用信到預設收件信箱。點擊信中的確認連結後，再提交一次即可收到 Word 附件。

## 本機預覽

必須使用 HTTP 伺服器開啟，不能直接雙擊 `index.html`。例如：

```powershell
python -m http.server 8080
```

再開啟 `http://localhost:8080/`。
